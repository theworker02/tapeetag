# tapeetag

Tape filesystem etag paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/tapeetag/

## Install / run

```bash
git clone https://github.com/theworker02/tapeetag.git
cd tapeetag
node src/cli.js
node --test
```
